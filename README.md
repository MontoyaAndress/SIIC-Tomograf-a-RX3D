# 🩻 RX3D — Sistema de Gestión para Clínica de Radiografía Digital

> Sistema web integral para la administración de citas, pacientes y personal médico en una clínica de radiografía 100% digital.

🔗 **Cliente en producción (Colombia):** [https://tomografiarx3d.com/]

📸 — por política de confidencialidad de la empresa, el código fuente no es público.*


---

## 📋 Descripción

RX3D es un sistema desarrollado para digitalizar por completo el flujo operativo de una clínica de radiografía: gestión de citas, historiales de pacientes, control de personal médico y administración de usuarios, todo bajo un esquema de roles diferenciados (paciente / médico / administrador).

## 👨‍💻 Mi rol

Fui el **desarrollador backend principal** del proyecto (trabajando en solitario en esta capa), responsable de:

- Diseño y desarrollo de **APIs REST** para la comunicación entre el frontend y la base de datos.
- Módulos CRUD completos (agregar, editar, actualizar, eliminar) para:
  - Doctores
  - Citas médicas
- Sistema de **autenticación y control de acceso** con roles diferenciados:
  - Pacientes (con ID único / código de acceso)
  - Médicos (con ID único / usuario y contraseña)
- Funciones de **administración de usuarios** (altas y bajas de pacientes y médicos) como responsable administrador del sistema.
- Participación puntual en frontend (colaboración menor; el enfoque principal fue backend).
